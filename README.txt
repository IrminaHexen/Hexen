HEXE – MAINE COON

1. Kopiere den gesamten Ordner nach:
   /home/oms/hexe

2. Hauptdatei der Website:
   index.html

3. Das Logo muss heißen:
   logo.png

4. Die Galerie nutzt jetzt bereits 8 bearbeitete Bilder:
   images/cat-1.png ... images/cat-8.png

5. Lokal im Terminal starten:
   cd /home/oms/hexe
   python3 -m http.server 8080

6. In Chrome öffnen:
   http://localhost:8080

7. Menüpunkt oben:
   Kontakt & Kauf

Hinweis:
Die Kontaktdaten in index.html sind Platzhalter und können später einfach ersetzt werden.
